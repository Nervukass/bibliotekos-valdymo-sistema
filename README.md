# Bibliotekos valdymo sistema

Dalinė bibliotekos valdymo informacinės sistemos realizacija, sukurta naudojant C#, ASP.NET Core MVC, HTML, CSS, Bootstrap ir JavaScript.

## Paleidimas

```powershell
cd WebApplication1
dotnet run
```

Atidarykite naršyklėje programos terminale nurodytą adresą.

## Funkcijos

- Bibliotekininko suvestinė
- Knygų katalogas su paieška ir žanrų filtru
- Knygos informacijos langas
- Išdavimų, rezervacijų ir skaitytojų langai
- Demonstraciniai, programoje įrašyti duomenys
